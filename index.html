Prepare content for review in TikTok.

Root Cause Studio is a planned internal tool for the Root Cause team to send selected finished videos and photo posts to its authorized TikTok account’s inbox. The account owner would review, edit, and publish the content inside TikTok.

This site documents a proposed integration. TikTok authorization, token handling, and uploads are not implemented here. No working upload or account connection is offered.

Proposed workflow

  1. Authorize the intended TikTok account through TikTok Login Kit.
  2. Select finished content in the local Root Cause Studio workflow and confirm it for upload.
  3. Send the content with TikTok’s Content Posting API using the video.upload permission.
  4. Open the inbox notification in TikTok to complete editing and publishing.

What remains to be completed

The integration needs a working local authorization and upload implementation, verified URLs where required, Sandbox testing, and applicable TikTok approvals. TikTok’s production review rules restrict private or personal-use apps; production availability for this internal workflow is unresolved.

Project information

Read the draft privacy notice and draft terms. Both need operator review before any integration launches.
