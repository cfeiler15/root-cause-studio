Privacy notice

This is a preliminary description of the planned integration, not a statement that data handling has been implemented. The operator must review and finalize this notice before enabling account connections or uploads.

This documentation site

These pages contain no analytics, tracking scripts, forms, or third-party embedded assets. They do not implement TikTok login or uploads. If published on GitHub Pages, hosting requests would be handled by GitHub under its own practices; this notice does not describe or control GitHub’s infrastructure logging.

Planned local integration

The proposed workflow would process the authorized TikTok account identifier, authorization credentials and tokens, selected media and metadata, and upload status responses. Tokens would be used locally to authorize selected uploads and renew access. Selected media would be sent to TikTok for inbox delivery; photo uploads would additionally require accessible media URLs on a verified host.

The storage mechanism, access controls, retention periods, deletion process, diagnostic logging, and any photo-hosting arrangement have not been finalized. These must be defined and documented before real account data or content is processed. Credentials must not be included in this public site.

External services

TikTok would handle authorization and uploaded content under TikTok’s privacy policy. GitHub describes its handling of site hosting data in the GitHub General Privacy Statement.

Open details

The operator’s contact channel, finalized data practices, and instructions for local data deletion remain to be supplied. No support address or retention promise is established by this draft.
